# Organization engineering guides

These guides help repositories adopt organization standards. The linked
standards remain normative.

## Developer Tooling

- [Developer Tooling Golden Path](../golden-path/README.md)
- [Adopting the Developer Tooling Standard](./adopting-developer-tooling.md)
- [Bootstrapping a new repository](./bootstrap-new-repository.md)
- [Migrating existing developer tooling](./migrating-developer-tooling.md)
- [GitHub hosting capability profile](./github-hosting-capabilities.md)

Developer Tooling uses a contract-backed, repository-owned Golden Path. The
Golden Path is an opinionated supported journey, not an active organization
locator, generator, checker binary, reusable conformance workflow, or managed
asset bundle.
